Навык: свойство сторон описанного четырёхугольника (суммы противоположных сторон равны)
Тип ответа: short
Баллы: 1
Рисунок: есть. Четырёхугольник ABCD, окружность касается всех четырёх сторон.
  Вершина B сверху, C справа, A слева-снизу, D справа-снизу.
  Asset: sources/fullpage-02.png (с. 4/36 официального PDF)
Условие:
  В четырёхугольник ABCD, периметр которого равен 22, вписана окружность,
  AB = 8. Найдите длину стороны CD.
Вопрос: найти CD
Ответ: 3
Тип значения: целое число
Решение:
  Если в четырёхугольник вписана окружность, то суммы противоположных сторон
  равны: AB + CD = AD + BC.
  Периметр: AB + BC + CD + DA = 22.
  Значит 2(AB + CD) = 22, откуда AB + CD = 11.
  Тогда CD = 11 − 8 = 3.
Подсказка 1: Вспомните критерий существования вписанной окружности.
Подсказка 2: Запишите равенство сумм противоположных сторон и периметр.
Подсказка 3: Периметр вдвое больше суммы любой пары противоположных сторон.
Источник: Демоверсия ЕГЭ-2027 проф., часть 1, задание 1, пример 1; ключ с. 17/36.
Примечание: в старом ege.txt формулировка была сокращена («противоположную ей
  сторону»), ответ 3 совпал.

Тип ответа: short
Баллы: 1

  DE — средняя линия, D на AC, E на BC, DE ∥ AB.
  Asset: sources/fullpage-02.png (с. 4/36)
Условие:
  Площадь треугольника ABC равна 60, DE — средняя линия, параллельная
  стороне AB. Найдите площадь трапеции ABED.
Вопрос: площадь ABED
Ответ: 45
Тип значения: целое число
Решение:
  Средняя линия отсекает малый треугольник CDE, подобный ABC с коэффициентом 1/2.

Подсказка 1: Средняя линия делит стороны пополам и параллельна третьей стороне.
Подсказка 2: Малый верхний треугольник подобен большому с k = 1/2.

Навык: сумма углов треугольника; свойство биссектрисы как луча, делящего угол
Тип ответа: short
Баллы: 1
Рисунок: есть. Треугольник ABC, C сверху, A слева, B справа, D на AB,
  AD — биссектриса, отмечен угол при A.
  Asset: sources/fullpage-02.png (с. 4/36)
Условие:
  В треугольнике ABC угол C равен 54°, AD — биссектриса, угол BAD равен 23°.
  Найдите величину угла ADB. Ответ дайте в градусах.
Вопрос: ∠ADB
Ответ: 77
Тип значения: целое число (градусы)
Решение:
  AD — биссектриса, поэтому ∠CAD = ∠BAD = 23°, и ∠BAC = 46°.
  В треугольнике ABC: ∠ABC = 180° − 54° − 46° = 80°.
  В треугольнике ADB: ∠ADB = 180° − ∠BAD − ∠ABD = 180° − 23° − 80° = 77°.
Подсказка 1: Биссектриса делит угол A пополам.
Подсказка 2: Сначала найдите угол ABC из суммы углов большого треугольника.
Подсказка 3: Искомый угол — в треугольнике ADB, там известны два других угла.
Источник: Демоверсия ЕГЭ-2027 проф., задание 1, пример 3; ключ с. 17/36.
Примечание: формулировка и ответ 77 совпали со старым файлом.

Подсказка 2: 7·(2; 2) = (14; 14).
Подсказка 3: Получится вектор (16; 12); это «египетский» треугольник 12-16-20.

        A = k θ0 · τ² / [ (T² − τ²)² + n τ² T² ],
  где k = 0,91 — коэффициент, зависящий от отношения ширины корабля
  к длине волны, θ0 = 9° — угол наибольшего волнового склона,
  τ — период волны (в секундах), T = 14,7 с — период свободных качаний
  корабля на тихой воде, n = 0,0792 — коэффициент, зависящий от величины
  сопротивления воды. При каком периоде волны амплитуда вынужденных
  колебаний корабля будет наибольшей? Ответ дайте в секундах.
Вопрос: τ, дающий max A
Ответ: 15
Тип значения: целое число (секунды)
Решение (официальный эталон ФИПИ, с. 26–27/36):
  Максимумы A и A² совпадают. Полагаем x = τ² > 0 и исследуем
  f(x) = x / [x² + (n−2) T² x + T⁴].
  f'(x) = 0 при x0 = T² / (1 − n/2).
  Это точка максимума.
  τ = T / √(1 − n/2) = 14,7 / √(1 − 0,0396) = 14,7 / √0,9604 = 14,7 / 0,98 = 15.
Подсказка 1: Константы k и θ0 на точку максимума не влияют.
Подсказка 2: Удобно исследовать A² и заменить x = τ².
Подсказка 3: После упрощения f' = 0 даёт τ = T / √(1 − n/2).
Источник: Демоверсия ЕГЭ-2027 проф., задание 17, пример 2; решение с. 26–27/36.
