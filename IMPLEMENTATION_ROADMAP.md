# IMPLEMENTATION ROADMAP — EGE CORE

Актуально на **5 сентября 2026 года**.

## Статусы

- **DONE** — работает через backend и SQLite.
- **PARTIAL** — рабочая часть есть, но объём ограничен текущим контентом.
- **TODO** — необходимая следующая задача.
- **FUTURE** — не входит в текущий этап и не имитируется в production.

## Текущее состояние

| Функция | Статус | Реализация |
|---|---|---|
| Backend и SQLite | DONE | `server/server.py`, SQLite-файл создаётся при старте; frontend общается с `/api/bootstrap`, `/api/state`. |
| Каталог математики | DONE | Предмет, уровни `basic`/`profile`, темы, навыки, задания, уроки, миссии, боссы и достижения хранятся в связанных таблицах SQLite. |
| Аккаунты и изоляция пользователей | DONE | HttpOnly cookie связывает браузер с записью `users`; все пользовательские таблицы имеют `user_id`. |
| XP, уровень, streak и активность | DONE | Рассчитываются из действий пользователя и восстанавливаются из SQLite после перезапуска backend. |
| Прогресс навыков | DONE | `user_progress`; изменения происходят после фактических ответов, уроков и испытаний. |
| Попытки и ошибки | DONE | `task_attempts`, `user_errors`, `lesson_step_errors`, `lesson_error_history`. |
| Интерактивные уроки | DONE | Черновики и незавершённые сессии сохраняются; завершения записываются в `lesson_attempts`; повторное прохождение не фармит XP. |
| Миссии, боссы и достижения | DONE | Состояние наград хранится в `user_missions`, `user_bosses`, `user_achievements`. |
| Daily Challenge | DONE | Реальные ответы и дневной прогресс сохраняются в SQLite; повторная награда не выдаётся. |
| Статистика и прогноз | DONE | Статистика считается из сохранённых попыток/агрегатов; дневные снимки прогноза не синтетические. |
| Онбординг и диагностика | DONE | Ответы диагностики и профиль сохраняются; стартовой фиктивной XP и случайного прогресса нет. |
| UI preferences | DONE | Только тема интерфейса остаётся в `localStorage`; прогресс аккаунта туда не пишется. |
| Существующий дизайн и маршруты | DONE | Сохранены vanilla JS, CSS, hash-router и основные экраны. |

## Удалено в переходе на рабочий режим

- локальные массивы каталога из frontend и прежний `DataAPI`-источник;
- хранение состояния в `localStorage`;
- функция заполнения демонстрационного профиля и кнопка demo-данных;
- случайный прогресс при диагностике;
- случайный выбор заданий в production-логике;
- текстовые обещания о локальном прототипе и будущей синхронизации;
- fallback на демонстрационные данные при недоступном backend.

## Что осталось TODO / ограничения

- Сервер сейчас использует анонимную cookie-сессию без полноценной регистрации, пароля и OAuth.
- API состояния принимает снимок, подготовленный application logic; отдельные командные endpoint-ы и серверная авторизация действий — следующий hardening-этап.
- Банк заданий небольшой и относится только к профильной математике.
- Полные страницы теории и библиотека уроков для всех навыков — TODO.

- `python3 -m py_compile server/server.py`
- `node --check js/data.js`
- `node --check js/state.js`
- `node --check js/app.js`
- `node test/smoke.js` — **ALL OK**.

- API isolation: два cookie-аккаунта получают независимые состояния.
- Перезапуск backend проверен чтением сохранённых данных из SQLite.
