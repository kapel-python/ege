# PROJECT CLEANUP REPORT — EGE CORE

Дата: **5 сентября 2026 года**.

## Итог

Проект переведён из local-first прототипа в рабочую схему `UI → application logic → HTTP API → SQLite`. Frontend больше не содержит каталог заданий и пользовательский прогресс как источник данных.

## Выполнено

- Каталог заданий, уроков, миссий, боссов и достижений вынесен в SQLite.
- Созданы связанные таблицы предметов, уровней математики, тем, навыков, заданий, уроков и пользовательских сущностей.
- Удалено хранение прогресса в `localStorage`; там осталась только тема интерфейса.
- Удалены функция и UI заполнения демонстрационными данными.
- Удалён случайный стартовой прогресс диагностики; профиль строится по ответам пользователя.
- Реальные ответы, ошибки, попытки уроков, статистика, дневная активность, streak, XP и награды сохраняются в БД.
- После перезапуска backend состояние читается из SQLite.
- Cookie-сессии изолируют данные двух пользователей.

## Проверено

- синтаксис Python и JavaScript;
- `node test/smoke.js` — **ALL OK**;
- API round-trip для XP, прогресса, активности и попыток;
- изоляция двух аккаунтов;
- отсутствие fallback на демонстрационные данные при недоступном сервере;
- production-поиск по `mock/demo/fake/random/localStorage`: совпадения остались только в тестовой/документационной классификации и в разрешённом UI-хранилище темы.

## Ограничения / FUTURE

- Аутентификация пока анонимная cookie-сессия.
- API использует снимок состояния; серверная валидация каждой игровой команды — следующий hardening-этап.
- Банк контента ограничен профильной математикой.
- Базовая математика, русский язык, обществознание, полноценная теория и пробный ЕГЭ — FUTURE.
